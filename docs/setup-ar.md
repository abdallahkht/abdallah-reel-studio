# ابدأ من هنا

## أسهل طريقة

نزّل [ZIP](https://github.com/abdallahkht/abdallah-reel-studio/releases/latest/download/abdallah-reel-studio-v0.1.1.zip)، وفك الضغط. افتح المجلد في مساعدك واطلب منه تجهيز المشروع. لا تحتاج حساب GitHub لتنزيل المستودع العام.

المتطلبات: **Python 3.10+** و**FFmpeg**، مع وصولك الخاص إلى Claude Code أو Codex للمونتاج بالذكاء الاصطناعي. المحرر نفسه لا يحتاج اشتراكاً أو API key.

## التجهيز اليدوي

ثبّت [Python](https://www.python.org/downloads/) و[FFmpeg](https://ffmpeg.org/download.html). على Mac، إذا Homebrew مثبت عندك:

```sh
brew install python ffmpeg
```

داخل مجلد المشروع:

```sh
python3 setup.py
```

هذا يفحص المتطلبات ويضيف مهارات المشروع إلى Claude وCodex بدون استبدال أي مهارة موجودة. احتفظ بمجلد المشروع في مكانه، ثم افتح جلسة جديدة ليتعرّف المساعد على المهارات.

لتجهيز قوالب الموشن أيضاً:

```sh
python3 setup.py --motion
```

هذا ينشئ بيئة `.venv` داخل المشروع وينزّل مكتبات رسم الموشن؛ لا يغيّر Python العام. في Windows، استخدم `python` بدل `python3` إذا كان هذا اسم الأمر عندك.

## فتح المحرر

على Mac افتح `launch.command`. إذا منع النظام تشغيل الملف الذي نزّلته، استخدم الطرفية من داخل المجلد:

```sh
python3 launcher.py
```

على Windows افتح `launch.bat`. على Linux شغّل أمر Python السابق. الرابط المحلي هو `http://127.0.0.1:4318`.

- **Open video:** افتح فيديو عمودياً. الفيديو النهائي وحده يمكن مراجعته وقصّه؛ لاسترجاع لقطات حُذفت سابقاً يحتاج المساعد توصيل الأصل وخريطة القص.
- **Notes:** ملاحظات بالوقت للمراجعة التالية مع المساعد. Delete يحذف الملاحظة وUndo يسترجعها قبل إعادة تحميل الصفحة. الإصدارات السابقة تبقى متاحة في السجل.
- **Export:** اختر الاسم والجودة، ثم Choose folder لفتح نافذة النظام. حدّد المجلد بنفسك ثم Export MP4. 2K هنا تعني 1440×2560، و4K تعني 2160×3840؛ التكبير لا يصنع تفاصيل إضافية.

الفيديوهات والمشاريع المحلية داخل `_deploy/` ولا تدخل في Git أو حزمة التنزيل. الملفات الأصلية تبقى في مكانها. لا تنقلها أثناء المراجعة، لأن المحرر يحتاج الوصول إليها.

إذا تريد تنزيل المهارات فقط، نزّل ZIP وافتح `skills/`. مهارات المراجعة والموشن تحتاج ملفات المشروع المرافقة، لذلك الاحتفاظ بالمجلد الكامل هو الأسهل.
