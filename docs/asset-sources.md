# Presentation asset sources

- `assets/claude-official.svg`: authentic Claude wordmark and star from the rendered navigation SVG at https://claude.com/, retrieved November 13, 2026. The light version sets the intended currentColor wordmark color for a dark background; path geometry and orange star are unchanged. Claude and its logo belong to Anthropic and are not covered by this repository’s MIT license. This independent community project is not affiliated with or endorsed by Anthropic.
- `assets/fonts/`: IBM Plex Sans Arabic Regular and Bold from https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic . Original OFL.txt included.
- `assets/studio-art.png`: original AI-generated cinematic editing artwork, created for this repository with the built-in image-generation tool. It is campaign artwork, not a screenshot of an implemented feature.
- Editor screenshots and review animation: actual local app, using only this repository’s synthetic motion examples. No private footage.
- Motion examples and GIFs: rendered from the included original Python renderer and JSON templates. They demonstrate motion scenes, not an end-to-end AI edit from raw camera footage.
